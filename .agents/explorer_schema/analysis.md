## Part 3: Seeding Logic and Execution

### Execution Flow
Seeding is executed **automatically on server startup**.
Inside `/Users/yanchimyeung/Projects/stock-dashboard/backend/server.js`:
- The function `seedAdmin()` is imported from `./scripts/seed.js` (line 27).
- It is executed within the `app.listen(PORT, ...)` callback on server startup (line 135).

### Data Seeded and Logic
The script `/Users/yanchimyeung/Projects/stock-dashboard/backend/scripts/seed.js` performs the following operations:
1. **Uniqueness Check**: Queries `prisma.user.findUnique({ where: { email: "admin@stock-dashboard.local" } })`.
2. **Short-Circuit**: If the admin user already exists, it prints `[seed] Admin user already exists: admin@stock-dashboard.local` and returns immediately.
3. **Password Generation**: If no admin exists:
   - Generates a random 24-byte hex string (48 characters) via Node's `node:crypto` library: `randomBytes(24).toString("hex")`.
   - Hashes it using the custom password utility: `hashPassword(generatedPassword)` imported from `../services/auth.js`.
4. **Database Insertion**: Inserts a new user record with:
   - `email`: `"admin@stock-dashboard.local"`
   - `passwordHash`: The generated hash
   - `role`: `"ADMIN"`
5. **Output**: Prints the generated email and plain-text password in a distinct CLI box structure to allow the operator to copy it, warning that it will not be displayed again.

### Interface with Prisma
The script imports a database singleton client wrapper from `../services/db.js` (`import prisma from "../services/db.js"`), which exposes the `PrismaClient` instance. It calls `prisma.user.findUnique` and `prisma.user.create`.
